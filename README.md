# Ubicaciones · app iOS nativa

App iOS (SwiftUI + MapKit) de Ubicaciones, la versión nativa de la web.

Este repositorio contiene **sólo la app** (`nativo-ios/`) y las imágenes que necesita la
compilación. El servidor y los datos NO están aquí.

La compilación del `.ipa` la hace GitHub Actions (`.github/workflows/ios-nativo.yml`)
desde la pestaña **Actions**, y el `.ipa` queda como *artifact* de la ejecución.
